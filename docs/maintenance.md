# Integrations maintenance and releases

The integration maintenance version documented here is `1.1.1`. This repository contains only plugins, ChatGPT adapter metadata, branding assets, and public-submission materials. It does not build the Server, Protocol, or Agent.

## Local builds

With Node.js 22 or later, run from the repository root:

```bash
npm ci
npm run build
npm run release -- build plugin --profile standalone
npm run release -- build plugin --profile connected
```

Builds produce prepared artifacts under `dist/` and `releases/`. Standalone is the default canonical profile and has no App identity binding. Connected is intended only for adapter validation with an existing App. Neither profile uploads, submits, deploys, or publishes to public channels.

Run `npm test` to check building, readback, and release-record constraints. Migration tests use fixed fixtures generated by the legacy Python tools. They verify canonical JSON bytes and file hashes for the historical standalone and connected inputs, plus ZIPs containing empty files, binary data, and Unicode filenames. Compatibility covers those plugin data and fixtures; serialization equivalence for arbitrary Python JSON large integers and floating-point values is unverified.

## Release boundaries

Public `.app` submission and public publication remain on hold. A successful build, historical App metadata, or an existing ZIP does not prove that a client has been updated. Record actual uploads, client selection, and tool calls separately. `remote-device-server` owns the MCP URL, OAuth, and service runtime state.
