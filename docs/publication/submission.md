# 公开提交准备

公开提交源码位于 `public/remote-device-hub/`，发布者名称为 EaseLian，类别为 Developer Tools。插件包提供 MCP 与 OAuth 声明、操作技能、品牌图标和 Apache-2.0 许可。平台身份验证、审核与发布通过目标平台办理。

## 检查材料

- 核对发布者身份、网站、支持、隐私和条款链接，并确认内容与目标服务一致。
- 使用 PNG 图标；当前列表与 composer 均引用同一个 256 × 256 品牌符号。
- 核对英文与中文说明、首次使用提示、支持地区和账户权益说明。
- 检查审核用例及预期结果，提供对应版本的真实演示录制。
- 通过平台安全字段提交审核凭据，凭据不进入源码、ZIP 或聊天。

`npm run package:draft` 生成草稿及缺失材料报告；`npm run package` 要求必填材料完整。以构建报告和平台保存的内容判断材料状态，不用源码字段代替平台验证。

## 审核账户与设备

使用只包含样例数据的独立账户。审核员必须能够独立登录，不能依赖开发者的邮箱验证码、手机或私人网络。Hub 服务所有者的恢复凭据不用于普通审核账户。

准备三个样例设备：在线可写且允许 shell 的 `review-linux`、禁止写入的 `review-readonly`、已登记但离线的 `review-offline`。前两者配置命名根目录 `workspace`，其中 `README.txt` 的内容为 `review-ready` 加换行。写入用例开始前确保 `review-example.txt` 不存在；每轮只清理用例创建的文件与作业。

## 用例与录制

[审核用例](review-test-cases.md)列出提示和预期结果。预期结果用于验收，不表示用例已经执行。

1. 展示插件名称、实际版本、连接状态和审核账户的样例设备。
2. 查询在线设备，显示实际设备 ID 和在线状态。
3. 读取 `workspace/README.txt`，展示真实返回值。
4. 创建文件，按读取到的哈希修改并读回；执行固定 printf 命令并显示退出状态。
5. 验证只读限制、未登记设备和离线设备的处理；只终止本轮创建的 sleep 作业。

使用录屏工具记录实际操作，避开密码、令牌和无关私人内容。完成后播放检查清晰度、结果和访问权限，再填写审核员可访问的真实 URL。截图或脚本不能替代录制。

## 提交与验收

材料齐全后构建严格 ZIP，在目标组织上传并核对保存后的元数据、连接配置、审核用例和扫描结果。身份文件与法律声明由有权代表公司的用户提交。审核通过后按平台流程发布，并按[客户端验收步骤](../chatgpt.md)分别验证 ChatGPT 和 Codex。
