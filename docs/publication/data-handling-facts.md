# Remote Device Hub — 隐私政策事实材料（未发布）

此文件用于准备真实的隐私政策，不是已生效的对外政策，也未代替运营者确定法律主体或承诺。
发布前需补充运营者、公开联系方式、面向地区以及经确认的保留和删除政策。

## 当前实现

- Google 登录接收并验证身份声明，账户记录包括身份提供方、subject、邮箱和内部用户标识。
- 设备绑定保存设备标识、名称、所属用户和 Agent 凭据的哈希；每个用户只能操作其自己的设备。
- 执行请求及文件内容、命令结果会经过服务中心转发，随后按工具调用返回给 ChatGPT。
- Cloudflare 在边缘终止 HTTPS，再以经过证书校验的 HTTPS 回源，因此 Cloudflare 和服务中心
  处在可以处理请求明文的位置；不能宣传为用户设备与 ChatGPT 之间的端到端加密。
- 设备命令以 Agent 的操作系统用户权限执行。文件工具受命名根目录限制，shell 不构成沙箱。
- 中心审计记录用户、客户端、设备、操作种类、时间和结果标记；当前审计表按全站约最近 10001 条保留，
  没有按天数自动删除的承诺。请求正文和命令结果不作为 audit 表的列保存。
- 带过期时间的会话/授权记录通过状态存储管理；过期记录在后续写入时清理，并非定时物理擦除保证。
- 用户可在账户/设备管理入口撤销设备或授权。完整账户数据删除和备份删除时限需要运营者另行确定并实现。
- 当前 Nginx 安全访问日志记录时间、来源地址、HTTP 方法、路径和状态，不记录 query、Cookie 或令牌。
  服务器日志和备份的保留期限应在对外政策中依据实际运维配置明确。

## 发布前不能虚构的事项

不能填写不存在的支持邮箱、声称已经通过公开审核、宣称数据永不经过第三方，或承诺尚未实现的自动删除期限。
网站、支持、隐私与条款链接应可公开访问，并与经验证的发布者身份一致。
