# Remote Device Hub: restrained steel palette

Created 2026-09-29 using the built-in ImageGen tool, editing the secure icon.
The owner disliked the bright cyan accent. This revision uses a graphite background,
cool silver monitor/arrow and muted steel-blue-gray padlock. The device, incoming
remote-operation arrow and closed-lock meanings remain intact.

Original and 16/20/24/32/48/256/512 pixel PNG exports use the `remote-device-hub-steel-`
prefix. Exports were mechanically resized with macOS sips; native 16, 24, 48 and
256 pixel images were visually inspected. The plugin manifest brand color is
`#A5B5C5`. The generated raster has slight tonal variation.

Prepared in plugin archive 1.0.3, based on the retained 1.0.2 archive. This is a local
package update, not a verified cloud installation or public directory publication.
The existing cloud App mapping, package identity and prior assets are preserved.

## ImageGen prompt

Use case: precise-object-edit. Asset: production app/plugin icon for Remote Device Hub. Image 1 is the existing icon to EDIT. User feedback: the bright turquoise padlock feels cheap and lacks a professional technical character. Make a restrained, precise infrastructure/developer-tool identity. Preserve the existing composition and meaning: large desktop monitor, large closed padlock centered inside the screen, thick incoming arrow entering through the upper-right opening, same scale and generous separations, no text. Change the palette and subtly refine geometry: background flat graphite-black #10161E, monitor and arrow cool porcelain silver #E6ECF2, padlock muted light steel-blue-gray #A5B5C5 with very low saturation. Absolutely no turquoise, cyan, neon, glow, saturated accent, gradient, metallic reflections, texture, chrome, bevel, 3D or ornamental circuit lines. The lock must still contrast clearly against the dark screen, including at 16–24 pixels. Use flat filled vector-like silhouettes, consistent structural stroke weights, precise square-aligned geometry, restrained small corner radii instead of soft bubbly rounding. Retain a visibly CLOSED thick lock shackle, filled solid lock body without tiny keyhole, clear arrowhead pointing into the monitor. Do not add a terminal prompt, shield, letters, network nodes or unrelated symbols. One finished opaque square icon, edge-to-edge dark background, no external padding, no mockup or sheet. Mood: rigorous engineering, quiet confidence, secure remote infrastructure.
