# Remote Device Hub: secure remote control icon

Date: 2026-09-29. Generated with built-in ImageGen, then exported to 16, 20, 24,
32, 48, 256 and 512 pixels using macOS sips. Original and exports are saved here
with the `remote-device-hub-secure-` prefix.

The monitor represents the target device, the large closed cyan padlock represents
authorized access, and the incoming white arrow represents remote operation.
Thick white/cyan shapes on navy improve readability in the small plugin picker.
The 16, 24 and 48 pixel exports were inspected at native size.

This is the selected replacement in cloud plugin package 1.0.2. The earlier
terminal-only (`bold`) and monitor/arrow (`control`) variants were superseded by
the user's feedback; neither was uploaded. The final package contains the secure
256 and 512 pixel assets and retains the prior cloud App mapping.

## ImageGen prompt

Use case: logo-brand. Redesign the supplied Remote Device Hub icon to communicate THREE ideas at once: a computer device, remote control coming from outside, and secure authorized access. Preserve its high contrast navy / white / cyan style. A simple production square icon optimized for 16–24 pixel display. Composition: a big WHITE desktop monitor silhouette/outline with a short sturdy stand fills about 82% of the canvas. Inside its screen, place a LARGE CLOSED CYAN PADLOCK as the focal symbol, with a thick closed shackle and solid rectangular body; the lock occupies about half of the screen interior, never a tiny corner badge. Add a short, thick WHITE diagonal arrow at the upper-right corner, coming from outside and pointing down-left INTO the screen toward the lock, visibly separated from the cyan lock; it must remain a distinct simple arrow, not a cursor or checkmark. Integrate the arrow with a deliberate gap in the monitor's upper-right outline so the frame and arrow do not visually collide. The closed lock itself is intact. Use only simple bold geometry: monitor outline thickness 8% of canvas width, lock shackle thickness 7%, arrow shaft thickness 9%, large triangular arrowhead. Layout must have generous navy negative space between monitor, padlock and arrow. Background solid uniform deep navy #0B1728; pure-white #FFFFFF monitor and arrow, bright cyan #55F5E6 closed lock. Overall symbol occupies about 84% of square with very little unused padding. Clean flat vector style, sharp clean edges with slight rounding, no terminal >_, no letters, no MCP text, no tiny details or keyhole, no orbit, no network nodes, no extra shield, no gradients, no texture, no shadows or glows, no 3D. One finished opaque square icon, no mockup or presentation sheet. Main reading order: secure computer under remote control.
